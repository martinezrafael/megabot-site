# megabot-site

Site institucional do **megabot** (RM Sistemas para Internet LTDA).

## Estrutura

- `index.html` — Página inicial + formulário HubSpot
- `contato.html` — Página de contato + formulário HubSpot
- `termos-de-uso.html` — Termos de uso
- `politica-de-privacidade.html` — Política de privacidade
- `status.html` — Status do sistema
- `assets/css/styles.css` — Estilos compartilhados
- `assets/js/hubspot.js` — Integração HubSpot Forms API v3
